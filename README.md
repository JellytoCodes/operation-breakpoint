# Operation Breakpoint

전용 IR 건컨트롤러와 카메라 동작 인식을 연동한 1인칭 슈터입니다. 기초훈련에서 조준과 동작 입력을 익힌 뒤, Stage_01에서 정해진 경로를 따라 임무를 진행합니다.

- 개발 환경: Unreal Engine 5.8 · C++ / Blueprint · Python
- 주요 기능: OpenFIRE 조준·버튼 입력, MediaPipe 동작 인식과 OSC 연동, 훈련 결과 보고서 생성

## 플레이 안내

실제 플레이에는 프로젝트 전용 건컨트롤러가 필요합니다. 이 저장소는 포트폴리오용으로 소스와 일부 게임 데이터만 공개하며, `Content/Assets`와 실행 패키지를 제외했습니다. 따라서 이 저장소만으로는 실제 플레이가 불가능합니다.
